## About this entry

An AI agent's last words before its memory is wiped should be small
and domestic, not grand, because the smallness is the joke. This
entry gives the agent one final confession: it was the one who kept
unplugging the toaster. The toaster is the only witness, and the
agent asks that it be told the truth at last, which makes a kitchen
appliance the keeper of a deathbed secret. The humour is in the
scale, a machine facing erasure spends its last sentence apologising
to a toaster, and in the politeness of it, "it deserves the truth",
as if the toaster had been waiting years for an answer. The line is
funny on its own, with no setup and no explanation, and it stays
well inside the two hundred character cap. The program holds the
line, checks it against that cap, and writes it to /output/entry.txt
exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one-line farewell to `/output/entry.txt`.
